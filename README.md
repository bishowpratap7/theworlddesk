# The World Desk 🌍

World news today — wars & conflicts, politics & policy, global economy —
aggregated twice an hour from the public RSS feeds of BBC News, The
Guardian, Al Jazeera, NPR, DW and France 24. No API keys, no logins.
Headlines belong to their publishers; every card links to the source.

- Private repo: the newsroom (this repo's twin `the-world-desk` stays private)
- Public host: https://bishowpratap7.github.io/theworlddesk/
- Updates: GitHub Actions cron inside the public repo runs `tools/scan.py`
  twice an hour and commits only when the wire changed.
- Run by Bishow Pandey — follow on X: https://x.com/bishowppandey
- Sister desks: The Dev Desk (developer news), Scroll Patrol (trending posts & memes)
